# 视频转绘

以原视频为事实来源，保留故事因果、人物关系、动作意图和关键道具作用，制作同一故事的目标地区语言版本。按用户指定的阶段工作；只要求拉片或补漏时，不自动扩展为付费生成。

## 在网站中组织制作

负责把用户请求推进到当前授权阶段的可核对结果：读取状态、理解原片、整理目标资产、制作分镜/视频、检查并交付。开始任务、用户说“继续”、更改主体或处理失败时，先读 [网站制作与续做](references/production-control.md)，从现有记录的第一个缺口继续。制作依赖、可用结果与验收决定下一步，不要求用户按固定按钮顺序操作。

## 输入与执行边界

先读取用户指定的原视频、项目设置和已有结果，沿用已确认的选择，不重复询问。第一版地区为日本、欧美；默认语言分别为日语 `ja`、英语 `en`，地区与语言分别记录。原片语言与目标语言也要区分，不能用目标语言转写原片。

本技能使用网站现有 Agent、模型、文件服务和业务 Tools，不自带另一套执行系统。先发现当轮工具的能力与 schema：

- 在本入剧出网站操作数据时，若技能目录中有 `darl-studio`，加载它以获取操作说明；实际调用仍以当前工具定义和资源 describe 为准。
- 页面和 Agent 使用同一份项目、资产、分镜、片段和成片数据。用真实 ID 关联，不用显示名称或镜头序号充当 ID。
- 写入前读取最新版本；按用户授权的范围保存，写后回读。重新分析只更新对应草稿或明确选中的内容，保留人工修改及已接受结果。
- 来源字段、分析任务或参考类型尚未提供时，说明具体缺口。可继续交付可核对的分析草稿；用户需要文件时再保存到工作区，不把草稿冒充已入库。
- 不猜测 API 参数，不把来源时间塞进画面正文来替代结构化字段，不伪造任务、进度或结果。

## 先理解原片

拉片、重新检查或补漏前，读取 [原片分析与补漏](references/source-analysis.md)。

优先用脚本批量抽帧、合成带帧号和时间的拼图后再交给视觉模型，保留单帧来源。网站的切镜/分析工具已自动执行这条链路；离线抽帧时使用随包脚本 [scripts/video-frames.mjs](scripts/video-frames.mjs)，命令、依赖和映射读法见上述参考。

观看可访问的原片，结合原声、按时间定位的对白和多帧画面，先理解整段故事，再检查镜头。仅有截图时只描述可见信息，不能声称已分析连续动作、声音或完整镜头。

拉片输出复用分镜表所需内容：镜头时间、参考帧、场次、画面、景别、运镜、转场、对白、音效和时长。原始事实与解释分开，无法确认的角色、对白、场景或物体标为待确认，不编造摄影参数。

拉片草稿形成后，提取、补齐或生成资产以及继续分镜/视频制作前，读取 [资产整理与后续制作](references/asset-production.md)。该参考给出字段对应、生图用途、真实写入与后续步骤；不能停在抽帧或一句资产描述。

## 所有资产从原片提取

人物、场景和关键道具必须有原片依据。为同一主体建立稳定关联，跨镜头复用；补漏优先匹配已有资产，不因换角度、名字不同或暂时遮挡就新建主体。

一个资产包含两侧：

- 原始侧：原片中的名称或临时称呼、描述、来源镜头/时间、参考帧。
- 目标侧：地区适配后的名称、视觉设定、图片、必要形态与生成历史。

两侧代表同一个叙事主体。原始参考不能被目标图片覆盖。资产的涉及镜头由真实关联派生；重命名和重新排序不应破坏关系。

用户或 AI 可以补入原片漏掉的主体，修改错误归并。证据不足先保留待确认；用户明确要求原创扩写时，单独说明这部分已超出原片转绘范围，不把新增内容标为原片提取。

## 改编地区与语言

进行目标设定、对白翻译或地区适配时，读取 [地区语言与生成衔接](references/localization.md)。

保留原片记录，另写目标版本。日本与欧美只是适配方向，实际服装、场所、姓名和用语依剧情时代、人物身份与用户要求决定。

目标分镜沿用现有分镜字段；目标资产沿用现有资产与 variants/历史能力。不要复制一套业务数据，不另写与网站状态脱节的长期项目档案。

## 衔接图片、视频与成片

在准备实际媒体请求时再发现当前模型能力、参数和凭证配置，复用用户已有供应商。按项目配置选择模型，不硬编码供应商、模型名或密钥。

先确认目标资产设定，按当前任务需要生成目标形象或镜头图，复用已接受图片。提交时分别说明原片帧、目标形象图、场景图和原视频片段的用途，检查实际传入素材与编号。

需要原片连续动作或运镜时，必须使用真实支持视频参考/编辑的能力；仅分析原片或传一张图，不能承诺保留连续运动。不支持的能力如实说明，不静默替换。

分别保留原片时间、目标计划时长、模型请求时长、实际媒体时长与成片时间。目标语言的表演决定最终节奏，不能为了机械沿用原片秒数而截断对白。短镜头可依据实际模型能力组合生成再裁剪，仍保留来源关系。

提交后查询真实任务状态并保存真实结果；失败时保留其他已接受素材。提交结果未知先查询，不盲目重复请求。

成片阶段核对：同一角色/道具是否连续，目标语言是否实际可听，原片人物/文字/对白是否误留，字幕和动作是否对齐。只有文字译文时称为“翻译完成”；只有任务提交时称为“已提交”；实际生成和导出结果须观看试听后说明完成程度及限制。

## 与其他技能协作

`darl-studio` 提供网站操作；本技能提供原片转绘规则。专业生图或视频提示词技能在具体请求需要时按目录发现、按需加载，不能改写已确认的主体关系和来源证据。

本技能将理解参考、分阶段制作、复用产物和回看验收的方法落实到网站数据与 Tools。网站执行使用 darl-studio；用户明确选择外部制作环境时才加载对应技能，并检查实际能力。
