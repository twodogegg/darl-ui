# 原片分析与分镜

查询当前原片的 `analyze` 任务；缺失时提交任务并用 `builtin_wait_video_redraw` 等待。服务端直接复用文件服务的 COS 原片地址，本地原片通过现有 COS 配置上传并校验，保留 fileId，无需网关文件上传。使用 PySceneDetect 生成候选切点，模型结合原视频校正切点并输出结构化分镜及资产和衍生状态，保存后用 `builtin_read_studio` 查询 `shots`、`assets` 核对。候选切点和模型判断均可能有误，用户可在分镜页调整或要求 Agent 使用业务工具修改。原片画面与原语言对白在 `shots.source`，目标画面与目标语言对白分别在 `description`、`dialogue`。视频转绘不要求单独生成剧本。接口失败则如实报告，保留已有数据。

按连续地点和时间组织场次，在场次的 assetId、variantId 关联场景与状态；同一场景可复用于不同场次。镜头使用 sceneId 归属场次，画面描述无需重复场景标签；场景不确定时标注待确认，不猜测。生成片段时读取场次关联并带入场景资产标签。
