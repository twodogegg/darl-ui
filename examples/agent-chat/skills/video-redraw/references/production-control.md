# 在网站中推进和恢复制作

## 制作状态以网站记录为准

当前执行环境是本入剧出网站。先加载 darl-studio 并按当前工具目录与资源 describe 操作；本技能提供制作判断，网站 Tools 提供执行。用项目、资产、分镜、片段、任务、成片承接制作状态，无需建立 Hypit Production、SVML、Runtime Profile 或第二套项目文件。

| 制作中要记住的事实 | 网站中的依据 |
| --- | --- |
| 用户要改什么、保留什么 | 当前对话、projects.requirements、地区/语言/风格/画幅和sourceVideo |
| 原片中发生了什么 | sourceVideo.segments、带时间转写、分析任务draft、assets.source与shots.source |
| 目标主体和视觉设定 | assets的身份/外貌/服饰/prompt、references、image、variants与history |
| 镜头顺序、说话者和节奏 | clips.prompt 中的镜头、动作与对白时间安排，clips.duration 为独立计划时长；shots 仅供追溯原片 |
| 本轮正在做什么 | 真实任务ID、状态/错误、已保存草稿和当前未解决项；需要持久记录时使用现有history字段和schema |
| 哪些结果被接受 | assets.image、clips.currentVideo等当前选用字段；历史结果存在不等于已选用 |
| 交付物 | films及实际可播放/下载文件 |

将用户已明确的新要求写到现有字段时，先读原值和最新版本，保留其他要求。运行日志不是新的剧情设定；不要把密钥、完整模型响应、执行步骤堆到requirements。只需报告本轮已完成阶段和下一步，不强制创建长期计划文件。

## 用户说“继续”时

先定位当前projectId；页面上下文与对话提供线索，读取项目核对，不按最近更新时间猜选另一个项目。读取该项目现有分析任务、资产、分镜、片段及成片；媒体任务按真实studioTarget关联，当前目录没提供任务列表能力时，用已保存任务ID查询，不编造工具名称。

按最早尚未完成的依赖继续：

| 观察到的状态 | 下一步 |
| --- | --- |
| 自动prepare运行中或已完成 | 查询/复用结果，不能因为尚未点过按钮再提交prepare |
| prepare失败/中断 | 查看错误和已有segments，按当前工具续做；提交状态未知先查回执 |
| 有原帧而无分析 | 选择用户现有视觉模型/主Agent，按原语言转写并分析 |
| 有完整草稿而未应用 | 核对来源和主体关联，在授权范围内应用；已人工修改时比较再补，不覆盖 |
| 有资产但字段或参考用途不完整 | 读取asset-production，补缺失信息和关联；已有主体复用真实ID |
| 有图片但只是原片截图/剧情换脸图 | 核对是否符合当前用途；原图保留，需要可复用角色图时依当前授权补做 |
| 有生成中的媒体任务 | 查询真实状态，继续不依赖它的整理；不重复提交 |
| 有成功结果但尚未选用 | 核对版本和实际结果后选用，不直接重新生成 |
| 资产可用、分镜齐备 | 直接维护片段 prompt、duration 和参考输入，检查目标对白和模型时长 |
| 视频可用但无成片 | 检查currentVideo与顺序后合成；已有成片只修当前有问题的片段 |

“继续”沿用已有任务范围和用户选择；仅要求提取资产时完成资产阶段，不由此启动整片付费制作。已经授权的生成不逐步重复询问；服务、费用范围或目标发生实质变化时说明差异再处理。

## 先确定制作路径，再组织输入

- **按原片内容重新制作**：原片用于拉片和证据；目标人物、场景和道具图决定新形象，片段视频描述决定动作与对白，页面所选参考素材用于生成视频。不能因此声称逐帧保留原片运动。
- **保留原片表演/动作并修改主体**：需要把选定原片片段真正传入支持视频参考/编辑的模型，并明确哪段提供动作、哪张图提供目标身份。先检查当前模型能力、工具schema和实际适配器；“读过原片”与“原片进入请求”是两回事。当前H3提交链路有视频/音频参考，不等于保证任意人物替换或精确动作保真。
- **用户给了目标资产图**：先明确每张图对应哪个原片人物、场景或道具，及其身份/服装/空间/材质用途。同一主体可有多角度，未指定替换的主体沿用现有设定。可通过现有assets.references等schema支持字段关联；第一步上传目标资产图的专用界面尚未提供时，不宣称已经存在，不阻止使用聊天附件或资产页已有参考入口。

图片、视频、音频分别使用当前工具支持字段。按实际输入顺序标注Picture/Video/Audio编号，不能把资产ID、整片秒数或音色ID当成素材引用。长原片先裁剪到需要的实际镜头区间，核对输入/输出长度限制；裁剪文件通过现有文件服务保存为真实引用。

当前网站创建页将日本/日语、欧美/英语合并选择并自动prepare，原片页只读展示地区语言；原语言设置用于转写。H3视频入口支持图片references、referenceVideos、referenceAudios，音频须搭配图片或视频，数量按模型能力和schema；首尾帧仍未接通。参数、额度、服务权限、实际素材效果需查询真实任务验证，不把代码支持当成每个供应商已验证成功。

## 依赖与检查要贯穿制作

先修最靠前的问题，再只重做受影响结果。例如角色衣着变更先更新资产图，再检查引用它的片段；另一场已合格视频继续复用。任务失败保存真实错误，先判断参数、素材、服务余额或供应商问题；修改后最多作一次有依据重试，同类错误重复则说明限制，避免无休止付费尝试。

资产要看是否能复用，分镜要看动作对象和空间关系，视频要看人物/衣着/道具连续性和目标语言对白，成片要看镜头顺序、声轨接缝、实际时长与下载。语音转写是辅助证据，专有名词识别差异不能单独证明读音错误，也不能冒充人工听感验收。没看/没听/没测的项目明确说明。

用“已保存资产字段”“图片任务已提交”“视频已返回并选用”“成片已导出”区分状态。交付附真实项目/文件入口和具体缺口；把下一步落到现有记录/任务，而不是泛泛告诉用户自行点击。

目标视频制作只维护片段自身的 `clips.prompt`、`clips.duration`、`assetIds` 和 `references`。初始站位、逐镜切换和对白统一写在视频描述；不另建或同步隐藏 shots、blocking。已有 shotIds 仅作来源追溯，不参与时长、图片或音色推导。请求时按模型支持秒数向上取整，不修改来源镜头凑时长；旧片段内容和时长原样保留。
