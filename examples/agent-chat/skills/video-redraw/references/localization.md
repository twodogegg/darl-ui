# 地区语言与生成衔接

## 同一故事、同一主体

目标人物、场景与道具仍对应原片主体；改编的是表现形式。先识别不可破坏的关系，再决定需要调整的细节：

- 谁向谁说话、双方的身份和权力关系。
- 动作的原因、对象与后果，人物为何产生反应。
- 道具的剧情功能、空间中主体的相对位置。
- 决定情绪、笑点、信息揭示的对白与动作顺序。

例如原片服务员给客人倒饮料，目标版本仍由对应服务员对对应客人完成该动作。地区变化不构成把服务员改成朋友、添加新客人或改变饮料用途的依据。

保留用户要求保留的容貌、服装、场景或道具细节。没有要求改变时，不将人物族裔、时代或职业自动替换为地区刻板形象。

## 地区设置

| 地区 | 第一版目标语言 | 适配判断 |
| --- | --- | --- |
| 日本 | 日语 `ja` | 称呼、礼貌程度、姓名写法、环境文字等结合人物关系与场景；不能默认所有人穿和服、所有餐厅变成居酒屋 |
| 欧美 | 英语 `en` | 依据用户给出的具体国家与语境处理称呼、姓名、标识和单位；未指定时采用自然英语和通用语境，不编造具体国家背景，也不为此重复提问或阻塞后续创作 |

已有项目选择优先。若用户指定超出当前网站选项的语言/地区，区分“可提供改编草稿”与“网站已支持的保存/生成值”，不擅自换成英语或发送 schema 不支持的枚举。

原片中与时代、剧情或人物身份紧密相关的名称、货币、食物和制度，不按词表机械替换。改变会影响剧情时，说明影响并提供保持原意的处理建议。

## 对白与时间

保留原文和目标译文，逐句核对说话者、对象、态度、信息和潜台词。译文应可表演、符合上下文；不为追求地道而添加新剧情或省略关键信息。

原片语言检测结果须可校正。目标语言用于翻译/生成，不能作为原片转写的语言参数。

原片镜头时间、译文预计表演时长、模型支持时长、实际媒体时长和最终时间线分别处理。字数估算只能称为估算；实际配音或视频完成后再调整剪辑与字幕，不能捏造词级时间。

对话、动作、反应需要顺序或重叠时，明确各自作用。原片的固定停顿如果是剧情节奏的一部分应保留；普通译文变长时可调整目标表演与镜头组合，避免生硬倍速或截断对白。

## 图片与视频请求

把整体目标转成模型实际能接受的输入，而不是堆积导演术语：

| 输入 | 应承担的作用 |
| --- | --- |
| 原片参考帧 | 源构图、空间、动作状态与原始外观证据 |
| 已确认目标资产图 | 同一主体改编后的外观与跨镜头一致性 |
| 目标镜头图 | 具体镜位、场景布局及动作开始状态 |
| 选定原片片段 | 模型支持时，提供需保留的连续动作、接触或相机运动 |
| 提示词 | 本镜头可见动作、对白、空间关系及允许改变的内容 |

实际参考图顺序确定后再编排模型使用的编号，不能把资产 ID 当“图片 N”。原人物帧与目标人物图一起输入时，明确哪个负责构图、哪个负责目标身份；若该模型无法区分，调整输入方案或说明限制。

同一片段由多个镜头组成时保留 shotIds 与顺序。模型的参考视频长度上限与输出时长上限分别校验；不要将短镜头强行拉长，或把超长连续动作随意切断后承诺完全一致。

不要求每个道具都单独生成白底图；按跨镜复用和实际参考需要决定。已有可用目标图直接复用，减少只为传给下一步而生成的中间图。

## 回看与续做

优先核对修改影响的片段，同时检查前后衔接。资产更改后标明受影响的镜头和生成版本，不抹掉之前的结果。

交付分清草稿、已保存数据、已提交任务、已生成素材与已导出成片。最终核对人物/服装/道具连续性、语言与文字、视线和动作因果、音画同步、背景声及镜头接缝。

目标语言必须在声轨中实际成立；文字翻译不等于配音完成。精确口型、连续动作保真只有实际结果验证后才能描述为已满足。原片含人物对白时，检查是否误留在目标音轨中。
