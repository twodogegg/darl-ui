# 分镜表编写

## 输入与范围

先确认项目、剧集、场次及用户授权的修改范围。读取剧本或原片分析、已确认的改编对白、项目资产及形态、已有镜头和来源证据。视频转绘以原片时间、切镜和已确认对白为依据，区分原片事实与目标改编；保留来源及已有人工修改，不凭一张静帧猜测动作或人物身份。存在缺口、证据不足或说话人不明时明确标注待核实，不编造事实或新增剧情。

在本入剧出网站操作时加载 `darl-studio`，以当轮 Tools 的 describe 获取字段；按其指导读取、写入和回读。页面分镜使用 `shots`，不把整张表只写在聊天或视频片段中。根据用户要求选择创建或修改范围，不擅自重写已有镜头或视频片段。

## 逐镜填写

- 镜头属于真实剧集和场次；遵循剧情或原片顺序，单镜时长采用已有可靠时间，不为凑整秒改变原片切点。
- 景别、运镜、切镜分别写在各自字段；运镜清楚描述运动或固定，首镜切镜为“—”。
- 画面描述只写可拍摄的内容：人物位置、朝向、动作、神情、空间和重要道具。用 `darl-studio` 的资产标签协议引用当前项目中真实存在的角色、场景、道具或具体形态；名称直接复制资产记录的完整 name。身份不明时用准确的普通描述，标记待确认，不猜测资产。
- 画面描述不写字幕、字幕文本、字幕位置、字幕变化或其他后期字幕说明；音效字段也不写字幕。原片字幕仅可作为 `source` 里的原始证据，不能把剧情中实体招牌、文件或画面内文字一概当作字幕删除。
- 音效写真实需要的非语言声音，如环境、动作及声源；不把对白、配音指令或字幕放在音效字段。无明确声音可留空，不编造音效。

## 对白：谁说、怎么说、说什么

逐条检查每个有发声的镜头，`dialogue` 按实际发声顺序保存，字段用 `{id,type,assetId?,speaker,description,text}`。`text` 只写实际发声的台词；目标语言和改编使用已确认的项目设置与对白，不把画面说明当作台词。无发声用空数组。

- `type` 使用页面支持的“角色”或“旁白”。角色发声须引用本项目真实角色资产 ID，画外发声不自动等于旁白；说话人未确认且无法关联时保留证据并报告待确认，不冒充某个角色或擅自把角色对白改成旁白。
- 每条对白都填写 `description`（怎么说）：简洁写可执行的语气、情绪、速度及画内/画外等已知发声状态，例如“画外，语速急促，带质问”。以音频、剧本或用户确认的表演意图为依据；只有发声方式明确时才写具体情绪。无法判断时写“语气待确认”（可加已知画内/画外），并在结果中列出待核实项，不伪称已听见或确定。
- 台词跨越多个镜头时，按实际时间和发声顺序分配，避免整句在每个镜头重复。已有分句或人工选择优先保留；不确定归属时说明待确认。

## 保存与核对

保存前逐镜检查：画面仅含可拍摄内容且无后期字幕；资产标签完整可解析；有对白的每条发声具备正确类型、真实角色关联（适用时）、台词和“怎么说”；景别、运镜、切镜、时长及来源符合已有证据。按版本写入后回读本次修改的镜头，核对字段和值，失败如实报告，未经回读不能声称完成。对于不确定项说明原因，不为通过检查虚构。
